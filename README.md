# استعلام کانفیگ (Config Checker)

ابزار وب برای استعلام وضعیت کانفیگ (حجم مصرفی، حجم باقی‌مانده و زمان انقضا) از روی **چند پنل X-UI / 3x-ui** به‌صورت هم‌زمان.

## ویژگی‌ها
- پشتیبانی از **چند پنل** (Multi-Panel) با مدیریت از طریق پنل ادمین جنگو.
- **استعلام موازی** همهٔ پنل‌ها و بازگشت سریع اولین نتیجه.
- **کش سشن لاگین** هر پنل (بدون لاگین تکراری در هر درخواست).
- پشتیبانی از لینک‌های `vless` / `vmess` / `trojan` / `ss` یا UUID / email / password.
- رابط کاربری فارسی **راست‌چین** و کاملاً آفلاین (بدون CDN/فونت خارجی).
- نمایش وضعیت واضح: فعال، منقضی، غیرفعال، حجم تمام‌شده، منتظر اولین اتصال.
- محدودیت نرخ درخواست برای جلوگیری از سوءاستفاده.
- رمز پنل‌ها در دیتابیس به‌صورت امضاشده ذخیره می‌شود.

## نصب سریع روی سرور (اوبونتو/دبیان)

فقط کافی است یک‌بار کلون کنید و اسکریپت نصب را اجرا کنید:

```bash
git clone https://github.com/MahdiTvK5/checker.git checker
cd checker
chmod +x install.sh update.sh run.sh
./install.sh
```

اسکریپت `install.sh` به‌صورت خودکار:
1. پیش‌نیازها (`python3-venv`, `pip`, `git`) را نصب می‌کند.
2. محیط مجازی (`venv`) می‌سازد و وابستگی‌ها را نصب می‌کند.
3. فایل `.env` با کلید امنیتی تصادفی می‌سازد و آی‌پی سرور را به `ALLOWED_HOSTS` اضافه می‌کند.
4. دیتابیس را مهاجرت و فایل‌های استاتیک را جمع‌آوری می‌کند.
5. سرویس `systemd` به نام `checker` می‌سازد و آن را روشن می‌کند.

اسکریپت موقع نصب **پورت را از شما می‌پرسد** (اگر 8000 اشغال است، مثلاً 8088 بگذارید).
برای نصب غیرتعاملی:
```bash
CHECKER_PORT=8088 ./install.sh
```

پس از نصب، سایت روی همان پورتی که وارد کردید بالا می‌آید:

```
http://<IP سرور>:<PORT>/          صفحهٔ استعلام
http://<IP سرور>:<PORT>/admin     پنل مدیریت (افزودن پنل‌ها)
http://<IP سرور>:<PORT>/healthz   وضعیت سلامت سرویس
```

### ساخت کاربر ادمین
```bash
source venv/bin/activate
python manage.py createsuperuser
```
سپس وارد `/admin` شوید و از بخش **پنل‌ها** پنل‌های X-UI خود را اضافه کنید (نام، آدرس، نام کاربری، رمز).

## به‌روزرسانی (بدون دانلود/آپلود دستی)

برای گرفتن آخرین تغییرات کافی است روی سرور اجرا کنید:

```bash
./update.sh
```

این اسکریپت `git pull` می‌زند، وابستگی‌ها را به‌روز می‌کند، migrate/collectstatic را اجرا می‌کند و سرویس را ری‌استارت می‌کند.

---

## نکات مخصوص سرور ایران

- **میرور pip**: اگر نصب وابستگی‌ها کند بود یا به مشکل خورد، از یک میرور داخلی استفاده کنید:
  ```bash
  PIP_INDEX_URL=https://mirror-pypi.runflare.com/simple ./install.sh
  ```
  (هر میرور داخلی دیگری هم که در دسترس دارید قابل استفاده است.)
- **رابط کاربری** هیچ منبع خارجی لود نمی‌کند، پس حتی بدون اینترنت بین‌الملل ظاهر سایت سالم می‌ماند.
- ارتباط با پنل‌ها داخلی است؛ فقط دسترسی سرور به آدرس پنل‌ها لازم است.

## اجرای دستی (بدون systemd)
```bash
./run.sh        # gunicorn روی GUNICORN_BIND در فایل .env
```

## اجرای محیط توسعه
```bash
source venv/bin/activate
python manage.py runserver
```

## اجرای تست‌ها
```bash
source venv/bin/activate
python manage.py test
```

## تنظیمات (`.env`)
| متغیر | توضیح | پیش‌فرض |
|------|-------|---------|
| `SECRET_KEY` | کلید امنیتی جنگو | (تصادفی در نصب) |
| `DEBUG` | حالت دیباگ (روی سرور `False`) | `False` |
| `ALLOWED_HOSTS` | دامنه/آی‌پی مجاز (با کاما) | `*` |
| `CSRF_TRUSTED_ORIGINS` | برای دامنه با https | خالی |
| `TIME_ZONE` | منطقهٔ زمانی | `Asia/Tehran` |
| `GUNICORN_BIND` | آدرس و پورت سرویس | موقع نصب پرسیده می‌شود |
| `GUNICORN_WORKERS` | تعداد worker | `3` |
| `XUI_URL/USERNAME/PASSWORD` | پنل پیش‌فرض (اختیاری، اگر پنلی در ادمین ثبت نشود) | خالی |

> توصیه: پنل‌ها را از طریق `/admin` اضافه کنید (قابلیت چندپنلی)؛ متغیرهای `XUI_*` فقط برای سازگاری و حالت تک‌پنل هستند.
